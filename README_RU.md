# SPORTS INTELLIGENCE PRO — PWA старт\n\nЕсть мобильный интерфейс для 7 видов спорта, PWA-манифест, Service Worker и минимальный FastAPI backend. Сейчас это демо: реальные матчи и аналитика не подключены. Ключи API нельзя вставлять в HTML/JavaScript — храните их только в секретных переменных серверного хостинга.\n\nСледующий этап: разместить `public` на HTTPS-хостинге, `server` на серверном хостинге, добавить ключи как Environment Variables, реализовать адаптеры API и проверить данные. После этого открыть HTTPS-сайт в Chrome на Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран». Затем подготовить APK через облачную сборку.\n
